用 EdgeTunnel 给自己搞个梯子!



前言：EdgeTunnel 是什么？

GitHub 项目主页：edgetunnel 是一个基于 CF Workers/Pages 平台的边缘计算隧道解密方案。它能够高效地处理网络流量，并提供强大的管理面板和灵活的节点配置能力。

说人话就是一个白嫖 CloudFlare 的边缘计算来搭建梯子订阅的项目，支持 VLESS Trojan Shadowsocks 三种协议



一、准备工作

1. 注册并登录 CloudFlare 账号

就算没有听说过 CloudFlare，你也肯定见过下面这个东西：

这就是 CloudFlare 提供的人机验证服务，但 CloudFlare 提供的服务可远不止于此，CF还提供CDN、安全防护等服务。我们今天便要用到其中的 CloudFlare Pages 和 CloudFlare Workers。

打开 CloudFlare 官网，注册并登录。


2. 注册并登录 ClouDNS 账号

ClouDNS 是一家专业DNS托管服务提供商，它的核心业务就是管理域名系统（DNS），我们等会需要用它免费注册一个CNAME域名来用。

ClouDNS 官网

二、开始部署！

1. 创建 Pages 应用程序

① 点击 direct-upload-demo.zip 下载 Cloudflare Pages 演示项目压缩包备用；

② 进入 CloudFlare 官网，点击侧边栏中 计算 > Workers 和 Pages > 创建应用程序 ；



注意！不是上面的所有选项，而是下面的 想要部署 Pages？开始使用!



③ 点击 拖放文件 > 开始使用



④ 项目名称 随便填一个就好，但必须是全新的名字，避免出现错误，推荐末尾补上任意数字，如 neko800767 ；

这一步填写名称后，CloudFlare 将会生成一个 你填写的名字.pages.dev 的网址，记住它，后面有用



⑤ 点击 内容，选择第一步下载的 direct-upload-demo.zip 压缩包，等待上传完成；



⑥ 点击 部署站点，等待部署完成；

⑦ 提示成功，代表初始化部署完成！



2. 设置管理员变量

① 进入项目设置页面，点击 设置 选项卡，添加变量和密钥：



② 点击 + 添加，类型 文本 变量名称 ADMIN，变量值是 管理员密码，建议设置复杂密码，避免被暴力破解；



③ 变量即可设置完成，如忘记密码可返回此页面查看



3. 绑定 KV 命名空间

① 点击侧边栏中 存储和数据库 > Workers KV > +Create Instance 创建一个命名空间；



② 命名空间名称可自定义，建议命名为 EDT2 以便区分，点击 创建 完成创建

③ 返回 Pages 设置页面，点击 设置 > 绑定 > + 添加 > KV 命名空间



④ 变量名称必须填写大写 KV ，命名空间选择刚刚创建的 EDT2，点击 保存 完成绑定；

⑤ 返回项目设置页面，确认绑定成功；



4. 重试部署，使其变量生效！

① 点击 edgetunnel-main.zip 下载最新版本项目压缩包备用；

② 点击右上角 创建部署 ，上传上一步刚刚下载的 edgetunnel-main.zip 压缩包；



③ 部署环境选择 生产，点击 内容，选择第一步下载的 edgetunnel-main.zip 压缩包，等待上传完成；



④ 点击 保存并部署，等待部署完成；

注意！如需修改管理员密码，修改完变量之后必须重新上传部署，否则变量无法生效！



5. 注册 自定义域名

① 我们在 “一、准备工作” 中已经登录好了 ClouDNS 账号，现在进入 ClouDNS 官网

② 选择 创建区域 > 免费区域

会看到可选的免费二级域名，比如：



③ 随便选一个就好，然后输入你想要的前缀，例如 neneneko .abrdns.com

④ 点击刚刚创建好的域名，进入域名解析设置



⑤ 点击 添加新记录， 类型 选择 CNAME ，主机随便填写，但一定要记得住，我这里填写 edt2

指向到 填写你在 “二、开始部署！” 步骤中 CloudFlare 生成的 你填写的名字.pages.dev 的网址



⑥ 点击 更新 ，几分钟后，解析就会自动生效！

6. 绑定 自定义域名

① 进入 Pages 应用程序，点击 自定义域 选项卡，点击 设置自定义域 ；



② 添加自定义域，输入你的自定义域名，点击 继续

③ 选择 开始CNAME设置 > 右下角稍后完成 DNS 设置

等待几分钟，显示 活动 说明自定义域已生效

恭喜！你已经成功部署好了 EdgeTunnel！



三、使用

访问 /admin 即可登录管理页面

例如我绑定的自定义域名 edt2.neneneko.abrdns.com ，则需要访问 edt2.neneneko.abrdns.com/admin；

输入管理员密码即可进入管理页面，直接复制自适应订阅链接导入你的客户端即可使用！

管理页面的其他东西如果看不懂就别动了喵~
